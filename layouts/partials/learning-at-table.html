Three reminders for a first turn

Say the attempt

“I want [result]. Kief tries [approach].” The DM calls for a roll when needed. You can ask for the spell to be read back.

Name the roll

A check resolves an attempt; an attack tries to hit AC; a save resists an effect. Use the printed bonus once. Report the total.

Keep the useful spell

Holding Pattern? Move toward safety, use a cantrip against an unaffected threat, or Dodge. Tell allies which targets to leave alone.

Use the ? hints beside controls: hover, focus, or tap to read; Escape dismisses. At a break, record resources remaining →
