Pair a liquid demonstration with one short label so the plan stays readable.

### When to use it

A visual model is useful but the group keeps confusing which feature is which.

### Mechanics

1. Use *Shape Water* for the simple liquid model.
2. On a separate Action, use *Elementalism* to write one word in nearby dirt or sand.
3. Ask a teammate to explain the plan back before anyone moves.

### At the table

“The part marked EXIT is my favorite part.”

### The rule underneath

These non-concentration cantrips can coexist within their own limits. Combining them does not create a new programmable map or supply missing terrain knowledge.
