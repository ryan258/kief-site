Separate remembered routes, rumors, and actual observations on a shared map.

### When to use it

The old map disagrees with the road in front of you.

### Mechanics

1. Use Kief’s History proficiency to investigate relevant remembered context if the DM calls for it.
2. Mark firsthand observations separately from reported claims with ordinary writing supplies.
3. Ask the navigator to select the route using the best available evidence.

### At the table

“The map is allowed to be old. We are not required to obey its mistakes.”

### The rule underneath

History is not Survival or remote sight. Kief’s tool proficiency helps with writing tasks when applicable, not automatic navigation.
